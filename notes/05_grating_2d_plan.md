# 5주차: 2D 라멜라 그레이팅 (주기 경계 + 수렴 테스트)

계획서 5주차: "2D 주기 구조 → 결과물: 그레이팅 흡수 스펙트럼 + 수렴 테스트 그래프"
진행 노트 5절 체크리스트(해상도 · 광원 · PML · flux · 종료 조건)를 항목별로 실험에 연결했다.

## 1. 구조와 이유
- Si 필름(t = 2 μm) 윗면에 폭 (1−f)Λ, 깊이 h 인 공기 홈을 주기 Λ로 판다. 예시: Λ = 0.8 μm, f = 0.6, h = 0.5 μm.
- 홈 그레이팅은 3D 나노홀의 2D 대응물이다. x 방향만 주기적이고 y 방향은 균일하다.
- f = 1, h = 0 이면 평면 필름이 되어 **1D 슬랩과 같아야 한다** → 구조 코드를 믿기 전 첫 번째 검증.

## 2. 수직입사에서 알아둘 물리 (계산 전 확인용)
- 수직입사이므로 Bloch 파수 k_x = 0. 주기 경계는 "같은 셀을 무한히 반복"과 같다.
- 공기 중 m차 회절은 전파하려면 Λ > λ 이어야 한다. Λ < λ 이면 ±1차 이상은 evanescent라 0차만 전파한다.
  → 그래서 Λ = 0.7–1.0 μm 범위에서 공기 쪽 회절 차수는 파장에 따라 켜졌다 꺼진다. 스펙트럼에서 이 경계가 보이는지 확인한다.
- 모니터를 x 전체 주기(size = Λ)로 잡으면 전파하는 모든 차수의 합이 들어간다. 부분 모니터를 쓰면 안 된다.
- 소스 편광: Ex (E 가 주기 방향 x 에 있음). Ey 편광(홈 방향 성분)은 나중에 필요하면 같은 코드에서 component만 바꾼다.
- 유도 모드(guided mode)로의 결합이 향상의 원인이라는 해석(Gao 2017 방향)은 **필드 맵으로 확인하기 전까지 가설**이다. 계산 결과로 증명된 것이 아니다.

## 3. 실행 순서 (이 순서를 어기지 말 것)
| 단계 | 실험 | 통과 기준 | 스크립트 섹션 |
|---|---|---|---|
| 1 | 평면 환원: f=1, h=0 vs coherent TMM | 해상도 올릴수록 max\|ΔA\| 감소, 최종 해상도에서 ≤ 0.1 %p | 체크 1 |
| 2 | 해상도 수렴 (940 nm, Λ=0.8) | 연속 두 해상도의 A 차이가 점점 작아짐 (차수 확인) | 체크 2 |
| 3 | PML 1 μm → 2 μm | \|ΔA\| < 0.001 (진행 노트 5절) | 체크 3 |
| 4 | 스펙트럼: Λ 3개 × 800–1000 nm, 같은 해상도의 평면 Si 와 비교 | 가장자리(800·1000 nm) 세기가 충분한지 확인 (1D 에서 약 1%) | 스펙트럼 |

- 1단계가 실패하면 그레이팅 결과는 보지 않는다. 1D 와 2D 가 다른 이유부터 찾는다 (PML, 셀 크기, flux 영역, 소스 면 크기 순으로 의심).
- 2단계 해상도 400 은 계산 시간이 길다. `--quick` 에서 100·200 으로 흐름을 먼저 본다.

## 4. 실행 방법 (사용자 PC, WSL2)
```
conda activate photontrap-meep
cd /mnt/c/projects/photon-trapping-project
git pull
python scripts/validate_grating_2d.py --quick
```
- `--quick` 결과는 `*_quick` 파일로 저장되어 git에 올라가지 않는다.
- 전체 실행은 시간이 길다. 1D 전체(9분)보다 훨씬 오래 걸릴 수 있으니 quick 결과를 보고 결정한다.

## 5. 아직 안 된 것 (솔직하게)

- 넓은 대역 한 번 계산(Lorentz 피팅)은 아직 없다. 지금은 파장마다 따로 돌린다 (진행 노트 6절 7번).
- 2D 결과와 3D 나노홀의 차이는 6주차에 확인한다.
- 체크 3의 PML 기준은 1D 에서 정한 값이 아니다. 2D 에서 처음 적용하는 기준이며, 결과에 따라 조정하면 그 이유를 기록한다.
