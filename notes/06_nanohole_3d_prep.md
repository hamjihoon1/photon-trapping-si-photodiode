# 6주차 준비: 3D 원기둥 나노홀 단위셀 (미실행 초안)

계획서 6주차: "얇은 Si 층(예: 2 μm)에 원기둥 나노홀 단위셀 구성 — 주기 700–1000 nm 범위에서 시작" /
결과물: "첫 3D 흡수 스펙트럼, 평면 Si 대비 향상 확인"

## 1. Gao 2017 값 (notes/02 에서 정리, 논문 본문 기준)
| 항목 | 논문 값 | 우리 프로젝트에 주는 의미 |
|---|---|---|
| 홀 지름 범위 | 600–1,700 nm | 원기둥 지름 스윕의 참고 범위 |
| 홀 주기 범위 | 900–2,000 nm | 계획서 시작 범위 700–1000 nm 보다 넓다 |
| 대표 조합 | d/p = 700/1,000 nm | 6주차 첫 번째 단위셀 후보 |
| 측정·시뮬 대역 | 주로 800–900 nm | 940 nm 정량 비교 기준이 본문에 없음 |
| 홀 깊이 | 메사를 관통해 p층까지 (구조 의존) | 우리 2 μm 슬랩에서는 깊이를 직접 정해야 함 (10주차 스윕) |

- 논문 소자는 n-i-p 메사 + SOI + SiO₂ 층을 가진 실제 구조다. 우리 6주차는 "얇은 Si 슬랩 + 홀" 모델이라 직접 비교가 아니라 경향 비교다.
- 논문 결과: 평면 Si 대비 850 nm 흡수 향상 약 10배(EQE 기준). 이 배율을 6주차 3D 결과와 비교할 때는 같은 파장 조건을 맞춰야 한다.

## 2. 6주차 첫 실행 계획 (순서)
1. 단위셀 설정: t = 2 μm, 원기둥 홀 d = 700 nm, p = 1000 nm, 깊이 h = 0.5 μm (5주차 그레이팅과 같은 값으로 두고 비교)
2. 해상도: 5주차 수렴 결과로 정한다. 3D는 2D보다 격자 수가 훨씬 많으므로, 먼저 낮은 해상도로 돌려 흐름만 확인한다.
3. PML 두께: 5주차 체크 3과 같은 방식으로 1 μm → 2 μm 비교 (3D 에서는 시간이 2배 이상 걸린다).
4. 평면 Si 기준선: 같은 셀, 같은 해상도로 홀 없이 한 번 더 돌린다 (향상 배율 계산용).
5. 800–1000 nm 스펙트럼: 파장 간격은 처음에는 크게(20 nm), 확인 후 줄인다.

## 3. 아직 정하지 않은 것 (교수님 확인 필요)
- 단위셀 대칭: 정사각 격자 vs 육각 격자 (논문은 육각 격자 사용)
- 홀 깊이 시작값 (논문 소자 구조 vs 우리 슬랩)
- 편광: Ex 단독으로 충분한지, 편광 평균이 필요한지
- 뒷면 매질 (6주차 결과에 직접 영향)

## 4. 실행 전 체크
- 3D 계산은 노트북에서 메모리와 시간이 크게 늘 수 있다. 시작 해상도를 낮게 잡고 메모리 사용량을 확인한다.
- 5주차 2D 판정(체크 1)이 통과한 뒤에만 3D 결과를 본다.
- 초안 코드 `src/meep_3d.py`는 Claude 환경에서 실행하지 못했다. 체크 1(평면 환원 3D 버전)을 먼저 통과시켜야 한다.
